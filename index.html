🔍 What Is Claude Code?

Claude Code is a tool that helps you write code using artificial intelligence. You can give it instructions in plain English, and it writes the code for you. Think of it as a smart assistant that sits right on your computer, ready to help you build software, fix bugs, or just learn to code.

🧩 Claude Code vs. the Claude Developer Platform

This is a common point of confusion, so let's clarify:

  • Claude Code – This is the desktop application (the one you will download here). It works directly on your computer, uses your own files, and connects to Anthropic's AI models to help you code.
  • Claude Developer Platform – This is Anthropic's online web service that provides the underlying AI models (like the "brain"). Claude Code uses this platform (with an API key) to access that brain. The Developer Platform is where you get your key and manage your account.

🔑 Getting an API Key

Claude Code needs to "phone home" to Anthropic's servers to use its intelligence. For that, it requires a special password called an API key. Here is how to get yours:

  1. Go to the Claude Developer Platform website. You can find the link by doing a quick web search for "Claude Developer Platform login" or by navigating to your web browser and typing "console.anthropic.com".
  2. Create an account if you don't have one. It is free to create, and you get some free trial credits.
  3. Once logged in, look for the "API Keys" section (usually in the left sidebar).
  4. Click "Create API Key". Give it a name (like "My Computer") and copy the long string that appears.
  5. Paste that key into Claude Code when it asks for it. The key is a long series of letters and numbers – treat it like a password. Do not share it with anyone.
💡 Tip: If you lose your API key, you can create a new one at any time. Old ones can be deleted from the same page.

⚠️ Common Gotchas And How To Avoid Them

Here are a few everyday stumbling blocks and their simple solutions:

  • My antivirus blocked the file. Some antivirus programs see new executables as suspicious. If this happens, click "More Info" and choose "Run Anyway". Or right-click the file and select "Run as administrator".
  • The app says "No internet connection" – Make sure your Wi-Fi or Ethernet is on. Claude Code needs an internet connection to work.
  • I typed my API key wrong – Copy it directly from the Anthropic website. Do not type it manually – it is very long. And remember to make sure you did not include extra spaces.
  • The program won't open – nothing happens. Try restarting your computer, then double-click the icon again. If that does not work, download the file one more time – the download could have been corrupted.
